# 📘 Proyecto de Registro de Equipos – TODOPC

## 🎯 Descripción
Este proyecto consiste en el desarrollo de una aplicación en **Java** que utiliza **interfaces gráficas con Swing** y **Programación Orientada a Objetos (POO)** para registrar los diferentes equipos que ofrece en venta la empresa **TODOPC**.

Los equipos que se administran son:  
- **Desktop**  
- **Laptop**  
- **Tablet**

---

## 🧩 Requisitos de diseño
Para el desarrollo de este programa se aplican los siguientes conceptos:

1. **POO y Herencia**:  
   - Clase base: `Equipos`.  
   - Subclases: `Desktop`, `Laptop`, `Tablet`.  

2. **Instanciación de objetos**:  
   - Se realiza desde una clase independiente con un método `main` (ejemplo: `inicio.java`).  

3. **Colecciones**:  
   - Los equipos registrados se almacenan en un `ArrayList`.
